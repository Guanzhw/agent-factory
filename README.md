# Agent Factory

Agent Factory 是面向可信小团队的 Agent 平台，基于 **Agno AgentOS 3.1.0 和 PostgreSQL**，采用 MIT 许可证。

默认应用是 AutoResearch。你在一个工作界面中提出目标、选择模型；助手自主选择工具、执行实验和整理结果。研究方法以可组合的 Skills 提供，不要求用户遵循固定的研究步骤。

平台负责账号、模型与工具连接、任务运行、停止和执行记录。成员管理自己的资源，也可以把资源共享给团队。管理员负责账号管理，普通研究任务不需要逐轮审批。

## 从本地使用开始

- **首次在 Windows 启动：**按[本地启动指南](docs/WINDOWS_LOCAL_START.md)准备 PostgreSQL、依赖、登录和 HTTPS。
- **服务已经启动：**按[研究会话指南](docs/PERSONAL_RESEARCH_SESSIONS.md)配置模型、提交目标并核对结果。
- **查找配置或实现细节：**从[文档目录](docs/README.md)进入对应主题。

安装包没有默认账号或模型密钥。默认启动提供本地文件与命令工具，命令使用服务进程的操作系统权限；会话工作目录不是操作系统沙箱。

## 当前可用范围

默认界面提供对话、执行记录、个人模型和统一设置。研究助手可使用文件与命令工具、个人偏好、临时子助手及同事助手问答。具体能力取决于已配置的模型和工具；聊天直接进入 Agno 执行。

原生 Windows 路径已实现。真实模型的小型 CPU 实验已执行并生成可独立复现的文件；这不等于完整部署验收。用户持久登录配置、注册产物下载、远端 GPU 分配和约 20 人的共享容量仍需各自验收。当前 SSH provider 不提供 GPU 绑定或分配。最新验证范围见[开发检查](docs/DEVELOPMENT_CHECKS.md)，关闭行为见[服务关闭说明](docs/SHUTDOWN.md)。

## 使用研究 Skills

默认包含研究迭代与结果分析两个可选技能。助手按任务需要读取说明、参考资料或执行技能脚本；已有文件、日志与外部结果都可用于分析，无需先创建实验或取得特定任务回执。

启动时会加载当前项目的 `.agents/skills`。外部标准 Skills 可放在本机目录，通过 `FACTORY_SKILL_PATHS` 指定一个或多个技能目录（Windows 用分号分隔，Linux/macOS 用冒号）。修改技能后重启服务即可加载。技能格式为 `SKILL.md`，并可包含嵌套的 `references/` 与 `scripts/`；无需改成 Factory 专用格式。

脚本参数按原样传入，默认在会话工作目录运行，也可指定其他工作目录，例如技能说明返回的 `source_path`。命令输出保留在会话中；需要从聊天下载的生成文件应写入会话工作目录。脚本没有项目默认运行期限，点击 Stop 会停止本地脚本进程。使用外部技能前，应了解其脚本会以服务账号的权限运行。

## 扩展平台

应用通过程序化装配接口复用底座能力。Agno 负责原生执行，应用负责研究策略和业务工具。部署代码装配聊天应用，直接使用个人模型和原生工具；无需先创建、发布或审批一套材料和应用。

- [架构](ARCHITECTURE.md)：理解底座、应用、适配器和装配代码的职责。
- [开发检查](docs/DEVELOPMENT_CHECKS.md)：运行与改动相关的检查。

根目录的 `department-agent-factory` 包默认启动 AutoResearch。独立的 `department-agent-factory-core` 包用于不包含研究应用的装配；包边界不意味着用户需要在两个研究入口之间选择。历史设计与验收记录保留在文档中，现行入口由[文档目录](docs/README.md)标明。
