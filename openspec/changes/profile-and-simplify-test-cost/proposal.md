# Proposal

## Why

PR96 已消除 CI 全量 Linux 重跑，但现有3198项套件的逐例/fixture成本和独立价值仍未量化。云端接手出现两项MCP收尾失败及Node夹具默认沙箱失败，需要从具体生命周期与环境证据定位，而非放宽时间界限。

## What Changes

- 在9a933aa基线和同条件最终代码上串行测量完整适用套件，分开setup、test、teardown、cleanup及共享fixture；保留通过、失败、跳过ID。
- 结合行为/平台边界精简重复旅程和无独立失效检出价值的测试；保留逐项覆盖映射，不按数量目标删测。
- 对MCP回调取消/收尾和Node进程隔离做确定性诊断，依根因修复且保留运行中UNKNOWN。
- 保存测量条件、初始失败、定向修复证明、同条件前后与最终完整检查。

## Capabilities

### New Capabilities

无。新增的测量是开发工具，不改变产品能力。

### Modified Capabilities

无新规范行为；修复现有停止证明契约实现，测试重构保持其风险边界。使用skip_specs，不为工具重构创建虚构能力。

## Impact

范围为测试/fixture、测量脚本、必要MCP修复和开发检查说明。不重复PR96的CI去重，不展开#97–102功能。主代理负责规范、重型测试和最终判断；子代理先只读研究再按明确文件范围实施。补充授权允许本阶段完成审查后推送独立分支并创建/更新Draft PR、检查精确CI；仍禁止合并、自动合并、部署、付费或真实模型调用。不得在基线测量期间混入后续功能。获拒操作仅有新增授权且确定未执行时才重试一次，不绕过。
