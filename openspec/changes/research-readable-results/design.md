# Design

## Context

此前真实截图来自9630候选的 `docs/images/research-session-subagents/`，代码呈现到本基线未变；本片必须重新浏览器验收，不能把旧截图称为新结果。仓库未安装两个用户指定技能；读取已核官方只读副本，没有安装或运行其脚本。

## Decisions

1. 使用 `react-markdown@10.1.0`，官方npm当前版本已核，React>=18与项目19.1.1相容。仅基础CommonMark，不加raw HTML、高亮、数学或插件链，不自写解析器。保持默认URL处理；图片展示alt文字，不自动请求外部图片。命令stdout/stderr和文件内容仍用pre，不作Markdown解释。
2. 主回复正常展开，子结果沿现有details。子助手状态与原任务按钮常显，完整分工目标可展开；内部ID与回执全文移入次级详情。操作回执确认、命令exitCode、任务完成是三种事实，不互相代替。未知/失败信息和核对入口始终可见。
3. 停止反馈直接消费当前会话state，不增加新的状态层。删除会在轮询后过时的固定成功提示；收到stop请求与实际stopped分别表达，模型正文不能更改运行状态。
4. ui-ux-pro-max固定源28b3b8d的可读字号/行长、键盘焦点、移动布局用于文本与展开控件；impeccable固定源6743a347的distill用于结论优先、原始细节逐步展开，clarify用于精确中文状态/下一步。使用本片已有浅色布局，无重新生成设计系统或假指标。

## Scope and Verification

只动ResearchSessions、局部回复组件、sessions.css、相应测试及依赖锁；不改导航、创建表单、业务工作台或API。首次浏览器证据保留实际响应来源：真实PG/密码登录中的已保存回复与工具状态；可另以明确fixture验证恶意Markdown和罕见状态，不混同实模。无需新Go任务：复用已取得真实回复原文用于视觉检查。

验收三个行为：读清主/子回复和代码；键盘/触摸展开分工及原任务往返且零执行写入；停止中/确认停止/UNKNOWN/失败不混淆。1440、390和320宽实际浏览器检查无页面横溢、代码原文和缩进保留、无外部图片请求；阅读/展开不能触发模型。

## Non-Goals

不支持任意HTML/GFM表格/自动外部资源预览，不重做执行机制或为模型不遵守ls提示增加授权框架。不宣称全站、真实GPU、容量或用户部署完成。后续继续应用/我的任务/我的资源、资源补齐返回、模板及维护路径，保留所有未合入旧工作。
