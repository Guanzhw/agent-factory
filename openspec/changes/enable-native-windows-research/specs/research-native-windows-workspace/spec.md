# Spec Delta

## Purpose

让使用原生 Windows 的个人 Research 用户在自己的会话工作区内完成读源码、搜索、精确修改和运行普通测试的编码闭环，并在取消或服务中断时保留可靠的本地停止事实与原操作状态，不因未知回执而重复执行。

## ADDED Requirements

### Requirement: 会话工作区在 Windows 保持文件边界

系统 SHALL 在显式配置的已有 Windows 工作区根下按 owner/session 隔离文件，接受现有以 `/` 分隔的相对工具路径；读取、搜索、编辑和命令 cwd 均 MUST 拒绝越界路径、Windows 设备/驱动器/流别名及 reparse/junction/symlink 目标，不能因目录被替换而访问工作区外文件。

#### Scenario: 中文和空格源码路径
- **WHEN** 授权用户在原生 Windows 会话工作区中读取和搜索含中文、空格路径的普通 UTF-8 源文件
- **THEN** 返回正确文本、相对文件名、匹配行号及现有截断信息，另一个 owner/session 不可借工具路径读取该文件

#### Scenario: 链接和路径替换不越界
- **WHEN** 输入包含 `..`、绝对/驱动器/UNC/设备路径、备用数据流，或祖先/最终目标是 reparse point、junction、symlink，或打开期间祖先被替换
- **THEN** 操作拒绝或继续使用已验证的原目标；不得读写外部目标，原错误状态不得被记作成功

### Requirement: 精确编辑保持已有回执语义

系统 SHALL 在普通单硬链接 UTF-8 文件上只替换唯一的指定旧文本，空旧文本仅用于新建；成功返回创建标记、前后 SHA-256 与实际字节数。系统 MUST 保留现有输出/编辑预算，而不能为 Windows 引入新的整文件大小上限。

#### Scenario: 普通大源码的局部修改
- **WHEN** 在超过 12KB 的已有源码中替换一个唯一小片段
- **THEN** 未编辑部分逐字节保持，前后哈希与完整文件对应；重复片段、不匹配、硬链接或已存在目标的新建请求不写入文件

### Requirement: Windows 普通命令返回真实输入输出和退出状态

系统 SHALL 在已启用 host command 的会话工作区内执行配置 PATH 解析出的普通可执行程序，保留 argv、cwd、stdin 与分离的 stdout/stderr、非零退出码及预算。命令 MUST 无 shell 展开，使用明确最小环境，不能继承服务凭据或自动安装依赖。

#### Scenario: 一次真实小型测试由红到绿
- **WHEN** 原生 Windows 上以已准备的解释器/测试依赖，在含中文和空格的临时目录读取/搜索错误源码、运行失败测试、精确修改后再次运行
- **THEN** 第一次记录真实非零退出码，第二次记录真实成功输出，工具哈希与磁盘修改一致；此协议测试不声称验证外部模型

#### Scenario: 三流同时活动
- **WHEN** 普通程序接收大于管道缓冲区的 stdin，同时输出 stdout/stderr，使用含引号、空格及非 ASCII 的 argv，或测试运行超过 30 秒但仍在既有配置预算内
- **THEN** 三流能持续推进，参数/cwd 正确、非零退出码如实返回、总输出预算仍生效且没有额外 30 秒包装上限

### Requirement: 停止以原进程树事实为准

系统 SHALL 在超时、取消、权限撤销、输出超限及根进程退出后清理该调用所属的 Windows 进程树和管道；只有从原调用的 Job 确认无活动进程并完成本地清理时才返回 stopped=true。创建期间及重复取消 MUST 等待托管恢复和清理，不得留下未托管运行窗口。

#### Scenario: 父退出而子持有管道
- **WHEN** 根进程先退出但同 Job 子进程仍执行或持有 stdout/stderr/stdin
- **THEN** 调用停止并确认整个原 Job，不能仅凭根 PID/退出码或关闭 Job 句柄报告整树已停止，也不能因管道 EOF 未到永久挂起

#### Scenario: 创建期间和重复停止
- **WHEN** 在原生创建返回前、Job 归属后恢复执行前、运行中或清理中发生取消，或连续提交停止
- **THEN** 尚未授权恢复的子进程不运行；已经产生的进程归原调用托管，清理结束才返回停止事实；无法确认时保留 UNKNOWN

### Requirement: 服务重启不重放未知副作用

系统 SHALL 继续按原 session/task/effect 身份保存和读取工具回执；服务硬退出后的未确认操作保持 UNKNOWN。Job 关闭导致本地进程终止 MUST NOT 被解释成先前没有副作用、成功完成或可自动重试。

#### Scenario: 副作用发生后服务硬退出
- **WHEN** Windows 命令已写入一个计数文件而服务在完成回执前硬退出，随后以同一隔离数据库和工作区重启
- **THEN** 原会话/任务/效果可查，UNKNOWN 阻止再次派发，计数仍为一次；已完成回执重读也不产生第二个进程
