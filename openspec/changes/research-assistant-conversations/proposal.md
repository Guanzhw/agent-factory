# Proposal

## Why

个人研究会话与已有助手问答仍分离：问题与回复没有持久归属，消息提交后尚未启动任务的中断也缺少可操作入口。整体目标是 Agent 在既有目标、共享权限、预算和停止边界内自主异步协作；首个小 PR 先接通人工发起的 UI 路径，再紧接自主工具发起与返回证据采用，复用已有消息、预算、原请求与回复机制。

## What Changes

- A 在自己的研究会话选择 B 的助手，确认并发送问题文本；不自动附带目标、历史、文件、私有记忆或凭据。
- 为原会话保存 owner 校验的消息关联与已发问题列表；B 可查看属于自己的原消息，在既有预授权 QA 配置和预算内回答。浏览器离线不影响已接受的原生任务。
- 首片人工路径中，消息已提交而无任务时由 B 明确接续原消息；已有 reserved/unknown/accepted 任务只核对原请求，不重新启动，不换 endpoint 或 allocation。
- 首片人工路径中，回复与证据在原会话展示并重新核权；A 选择一条回复提交下一轮，这是 UI 使用方式，不是所有消息或证据必须人工审批的规则。
- 复用接收方原任务入口及停止权限；A 停止自己的会话不获得停止 B 任务的权限。旧独立问答入口和历史数据保留。

| 路径 | 交付顺序与验收 |
| --- | --- |
| 人工 UI 发起 | 首个小 PR：确认文本、B 预授权 QA、原会话回复卡片、选择后下一轮采用；覆盖丢 ACK、重启、重复及两用户拒绝。 |
| Agent 自主异步协作 | 紧接续片：沿获准目标和资源范围主动询问、通知并自动关联/采用返回证据，无逐条人工审批；覆盖离线返回、重复事件、预算/停止、撤权及 UNKNOWN 不重放。尚未接线，不宣称已实现。 |

共享的权限、预算和原操作核对保持有效；超权限、修改他人资源或未知副作用仍阻止或核对。不新增第二消息总线、角色系统、群聊/Team 或训练执行。

## Capabilities

### New Capabilities

- `research-assistant-conversations`：研究会话与助手问题/回复关联；区分首片人工 UI 路径和紧接的获准自主异步路径。

### Modified Capabilities

无。主规范目录当前为空；既有 change 中的消息准入、防重放、私密回复、个人研究会话与上下文整理契约继续适用。
