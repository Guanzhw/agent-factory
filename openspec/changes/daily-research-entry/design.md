# Design

## Context

用户已授权全站易用性整改；本片是第一条完整跨页任务。旧task-oriented spec基线3ec76ad已经落后，当前已有长期研究会话、模型maxOutputTokens、记忆和子助手，不能整文件覆盖旧ModelSettings或研究路由。现有App.navigate合并合法查询参数，Research已有owner草稿和确认退出后的清理，先复用。

## Decisions

1. 沿用tab/router/composition。主导航呈现三日常入口；作者与维护以次级分组保留真实入口，不为重排增加路由引擎。当前页、手机展开及键盘焦点可辨。原账号入口仍只对既有manager显示，服务端权限不变。
2. 保持安装应用与任务模板的区别，不将普通应用目录接到所有published定义。Research自动发布的内部定义要求sessionId/turnId/sessionContext，旧分页补丁会把它们当作成员模板；其来源分类须在后续模板片独立定约。本片不按名字或schema猜用途，不让core读取Research私表。
3. 资源入口直接通向模型、服务器、工具、远程服务和凭据的现有对应能力；绑定/租约等低频记录仍可达。用最小已知类别参数或现有区域定位，不创造新的配置能力。切换不能悄然丢弃已输入内容；按实际编辑状态保留或明确允许放弃，不新增通用表单引擎。
4. 模型页保留现有保存/设默认/输出额度/凭据引用/轮换/共享/原请求机制。源码已具有maxOutputTokens全链，所有保存路径必须保留它。把另一条模型设默认不应清掉正在编辑的新模型草稿。必填错误放在对应字段，秘密保持组件内存，不进入URL或浏览器草稿。
5. 从Research进入资源保留项目或researchSession/researchView及已有草稿。仅在真实保存流程确认后提供清楚的返回原研究动作；失败或结果未知不自动返回。返回后明确仍需选择/核对模型并由用户开始，不能默默替换旧会话的固定绑定。普通资源入口没有虚构的研究来源。
6. 未保存输入的离开、后退/前进、刷新和退出只补本片实际需要的保护，复用现有owner草稿/原请求存储；不要直接移植旧不存在的workspaceForms抽象。已有安全退出与换成员清理保持不变，不迁移/保存秘密。
7. 延续浅色侧栏与独立Research壳。ui-ux-pro-max的清楚导航、就地错误和焦点，impeccable clarify/distill/operate的任务名称、按需展开和必要步骤支撑本片；具体官方固定来源沿已有设计审查记录，未安装技能或运行脚本。

## Verification

真实隔离密码登录/PG/API验证普通空目录与显式Research、资源保存拒绝/成功及来源往返；新模型仅用明确测试配置，不请求外部模型或创建生产凭据。桌面1440及手机390/320，研究项目与新会话两种来源、后退前进/刷新、重复保存、输出额度保留、退出换成员隔离。未知回执可用明确fixture，服务端真实拒绝和客户端校验分开。打开或返回不得创建任务/模型调用。

## Non-Goals and Next Slices

任务列表/计划/创建记录的内容整理、模板来源分类和分页/作者流程、存储/历史只读/账号页随后逐片完成；本片不假称这些已重做。用户可访问部署须等完整UI与已授权可用环境，不把loopback测试称为部署。Agno、执行状态与研究业务工作台不改。
