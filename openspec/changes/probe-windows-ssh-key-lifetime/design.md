## Decision
Probe only: create a directory and synthetic OpenSSH private key with a protected current-token-user-only DACL supplied at creation. Reject reparse points and verify owner/DACL before writing. Keep a non-inheritable DELETE_ON_CLOSE file handle open while system ssh-keygen.exe -y reads the path. Compare its captured public key to the in-memory synthetic public key; never print either key or stderr.

A parent runs two bounded keeper subprocesses. The normal case closes its handle; the crash case is terminated using Windows TerminateProcess while the key handle remains open. The parent checks key absence after both, then removes only its own directory. No finally-only cleanup claim. The synthetic key exists only in child memory and the protected candidate file. No key is passed in argv/environment or retained in logs.

Exit 0 means candidate accepted; exit 2 means completed experiment rejected the candidate (including key-loader sharing failure); exit 1 means experiment incomplete/framework error. Safe JSON includes experimentCompleted, candidateAccepted, readable, numeric/API error codes, executable versions, and cleanup observations. OpenSSH stderr is captured and classified only for recognized sharing diagnostics, otherwise a fixed loader-rejected code; it is never emitted. Missing Windows/system binary is an incomplete experiment. Each subprocess and loader has a deadline; the overall script is bounded by 60 seconds.

## Evidence boundary
The upstream Windows file loader uses FILE_SHARE_READ|FILE_SHARE_WRITE for O_RDONLY, without FILE_SHARE_DELETE: https://github.com/PowerShell/openssh-portable/blob/latestw_all/contrib/win32/win32compat/fileio.c#L304-L310 . Windows sharing rules: https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew . Installed versions must be measured. A successful key-loader probe does not establish ssh.exe authentication, portable pipe IO, Linux helper execution, power-loss erasure, or protection against administrators/current-user processes. No fallback to plaintext files, global ssh-agent, ASKPASS, or a custom agent is included.
