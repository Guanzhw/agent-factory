# Why

The research evidence consumer needs actual completed CLI outputs. Child model text is not execution evidence; applications must not query core effect tables or infer tool identity from output shapes.

# What Changes

Add one owner-only Python application port for original CLI results. It accepts exact task/run identity and proves a single persisted CLI operation in the original ordinary executor plan before exposing successful personal-tool receipts. Unsupported provenance returns an explicit conflict. No HTTP route, dispatch, credential resolution or publication is added.

# Capabilities

## New Capabilities
- `original-cli-results`: original owner-bound results and immutable single-tool provenance.

## Modified Capabilities
None.

# Impact

ApplicationRuns and focused tests. The concrete consumer is the research selected-evidence change; output remains private until its owner-confirmed field selection.
