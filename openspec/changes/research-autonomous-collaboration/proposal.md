# Proposal

## Why

PR #153 把问题和回答带回原研究会话，但仍依赖成员发问和选择回复。下一片让个人助手在已授权的目标、共享范围和运行限制内完成一次自主异步问答，成员可查看、纠正或停止，无需逐条批准消息。

## What Changes

- 新配置研究会话提供同事助手查询/发问工具；原 owner、研究会话和幂等请求从可信运行上下文派生，只发送 Agent 明确提供的问题文本。
- B 的现有问答配置、预算和原生执行负责回答；私人回复沿已有投递生命周期回到 A，不发布为团队材料、不共享私人会话或凭据。
- 活跃 A 在下一模型安全点核权并采用；已安全结束的 A 可在原发问时保留的有界继续意图内创建一次新轮，不复活旧 run。停止、预算/轮数不足、授权撤回或原操作 UNKNOWN 均不自动执行。
- 界面显示正在等哪条问题、回复已到/待纳入/已纳入或受阻的真实状态，保留原问题、来源、任务和人工入口。
- 旧会话固定的应用/工具版本不热扩权；现有记录、消息和任务保持可查。继续采用 Agno 3.1.0。

## Capabilities

### New Capabilities

- `research-autonomous-collaboration`：受当前研究运行授权约束的自主问答、私人返回与有界继续。

### Modified Capabilities

无已归档主规范；已有 `research-assistant-conversations`、个人会话/上下文及消息投递契约继续适用。本片落实前片明确保留的自主路径，不重定义其人工入口。

主要影响 Research 的工具注册、原会话问题关联、模型安全点和界面，以及 core 现有 AssistantMessages / AssistantEvents 的私人回复投递接线。core 不导入 Research；不新增第二消息总线、独立调度器、泛化 agent 框架、Team 或角色系统。私人回复投递与闲置会话继续当前尚不存在，必须经独立方案审查及真实 PG/原生运行验证，不能以内容事件名称相似代替实现。
