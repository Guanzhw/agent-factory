Preserve the exact command and oracle for a bounded diagnostic run. Obtain only fixed booleans for public-key-authenticated, bounded stdout/stderr presence, known shell syntax/command-not-found/access-denied/channel failure markers, and truncation. No actual output/path/prompt/key is published. No server or account change is authorized by this failure.

Diagnostic implementation after independent design PASS: optional probe stderr redirection preserves the default DEVNULL behavior for all original Stage A callers. Stage B reads bounded private client/remote diagnostics into fixed booleans only. Two portable synthetic log fixtures confirmed authentication/shell marker discrimination and truncation/missing-file behavior; a private canary was not returned and every diagnostic value was boolean.
