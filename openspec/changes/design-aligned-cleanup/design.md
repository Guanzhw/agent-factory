# Design

## Context

动机见proposal。基线提交31d4ed62的源码树10e78a31与已合入main a9958e97一致；使用独立工作树，保留首次14项审查原件。原始v0.3私有文档仅作为历史依据，不复制进公开仓库；后续决定以ADR 0001/0002、CONTEXT.md、可信团队简化与Research旅程文档核对。

## Goals / Non-Goals

**Goals:** 在实际输入、持久化和外部效果边界保留唯一权威校验；删除同进程重复证明、退役门面和无依据的固定限制。修复原请求恢复、精确版本选择、完整资源发现与真实研究结果复用。

**Non-Goals:** 不引入第二套执行/恢复/审批框架，不迁移旧表，不恢复已撤销凭据，不扩大已确认任务的保存预算，不改私有资源访问边界。本次不部署、不自动合并。

## Decisions

1. **保留职责，减少实现。** Agno仍拥有队列、运行和会话生命周期。Factory仅保留资源绑定、语义幂等、共享预算和外部效果归属。删除无消费者owner-submission门面和审批写客户端；历史GET、410和数据库记录保留。拒绝为清理另建治理层。
2. **原操作清理不重新取得执行许可。** 新提交要求当前成员、执行绑定和可用凭据；已存在操作的inspect/cancel/output/恢复仅使用原始不可变绑定及仍可用的精确凭据。撤销执行权限不能阻断停止。内部远端结算复用已有生命周期观察者的原ticket/envelope读取；不能借此开放禁用成员的一般HTTP查询。旧发现3的内部误用修复，但跨服原端若只有已禁用接收账号的HTTP凭据，仍无法取回回执；本次不为此新建服务器身份/密钥通道，也不声称端到端结算完成。
3. **并发和预算使用已有权威。** SSH删除宿主根锁，保留原租约目录原子创建、原绑定和SQLite事务。祖先约束统一用于预览与创建，保留现有根锁；保存的maxDepth继续表示根相对绝对深度，maxChildren按各自子树计数。worker保留默认值、正整数配置和实际容量预留，移除固定四个的审批门槛。
4. **恢复依赖原命令回执。** 计划恢复返回原命令身份及现投影，后续编辑不抹掉完成事实。仅明确的直接写前拒绝解除浏览器pending；未知结果仍查询原操作。应用选择使用精确版本引用。所有者ID使用账号契约，客户端不重复改变服务端接受的URL字节。
5. **普通数据不作为执行配置。** 通用完成输出接受有限JSON，删除业务字段、URL、换行黑名单。Research命令输出只使用一个实际声明的有限预算，并计入序列化开销。保留真实停止证据、效果身份、大小和JSON边界。
6. **可持续研究由用户的实际授权约束。** 普通历史保留在存储中，当前指令、最新纠正、目标/边界和未结效果身份保留在投影；安全终态的旧用户/助手文本交给现有Agno摘要通道作为非授权背景。原生task session与长期Research身份不同，继续使用现有临时会话摘要/checkpoint，不新建上下文框架。手动新消息授权保存的每轮预算，可越过永久会话轮数门槛；原自动协作额度不重置或扩大，未知操作仍查原身份。离线QA使用现有定义发布/配置操作，以稳定派生请求ID把内部版本仪式折叠到一个有意义的授权动作。拒绝简单放大常量或回写旧预算。
7. **完整发现适合当前团队。** 保持现有扁平列表返回值，移除应用/资源/凭据无感知的100条截断。保留本来就显式分页的账号与历史接口，不新增分页框架。

## Risks / Trade-offs

- 更完整的列表增加小团队单次返回量 → 保持查询/序列化简单，以现有负载为目标；未来有测量再分页。
- 清理身份与执行身份分离可能误开放重放 → 回归必须证明撤权后的原操作可停、不可再次提交，禁用用户仍不能一般读取。
- 输出字节与JSON转义不等长 → 针对实际序列化边界验证，超限仍停止归属进程并保留不确定性。
- 多领域改动容易遗漏交叉契约 → 按文件归属并行实施，集中更新OpenSpec任务，完成针对性测试与独立复核。

## Migration Plan

无数据库迁移。旧记录保留原引用与预算。先完成合并清单、最小修复和简化，再运行受影响检查、审查差异，提交中文Draft PR。回滚使用正常代码回退，不清理用户目录或旧数据库。

离线QA的最低工作量来自实际注册步骤。新配置、可用性投影和原问题上下文共享该检查；历史配置使用其原保存额度及原任务计划，在模型请求前拒绝不足额度，不自动提额。原回复恢复不重新消耗新问答额度。

GitHub依赖告警补审确认certifi和OpenTelemetry API的上游修复版本。只更新这两个锁定记录并保留官方PyPI来源、77个包的集合及Agno 3.1.0；不以手写证书黑名单或新的请求审批替代上游补丁，不修改系统证书或旧环境。
