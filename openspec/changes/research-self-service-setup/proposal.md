# Proposal

空库中的成员能保存模型和工具连接，但现有应用管理只能复制已发布定义或输入高级JSON；注册research-round Workflow不会自动产生可运行应用。补研究应用自己的窄setup消费者，复用现有材料/应用治理，不恢复启动种子或另造composer。

成员选择已有模型连接、真实已安装环境adapter及已发布实验工具材料，保存可检查的研究定义草稿，显式确认发布后得到精确applicationRef和本人的连接映射。setup不执行模型、工具、环境准备或训练。本文仅覆盖setup.py、相关测试与契约；HTTP安装和浏览器由集成作者接入，浏览器空库完整旅程未通过前不宣称产品可用。
