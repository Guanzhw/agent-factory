# Comparisons

Compare like with like: data split, units, objective, runtime conditions and evaluator version can change the meaning of a score. Note material differences rather than inventing a standardized experiment protocol.

When variability matters, inspect repeated observations or uncertainty estimates supported by the data. A single improvement is not automatically robust. Do not claim statistical significance without an appropriate calculation.

Distinguish execution failure, a valid negative result, missing data and an unknown outcome. Report useful partial conclusions while retaining these distinctions.
