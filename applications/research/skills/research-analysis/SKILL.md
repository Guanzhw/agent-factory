---
name: research-analysis
description: Interpret and compare research outputs, files, logs or external results and write a useful conclusion. Use for analysis, follow-up decisions and explaining uncertainty.
---
Use whichever evidence is actually available: ordinary files, previous results, tool output, remote observations or shared records. Analysis does not require a completed Factory experiment or a terminal task ID.

Separate observations from interpretations. Check units, denominators and the conditions behind a comparison. Inspect raw output when a summary hides the relevant detail. Prefer a simple calculation or the task's evaluator over a new analysis service.

Identify what the evidence supports and what it does not. Propose a next check only when it could resolve a relevant uncertainty. An incomplete or unknown result can still support a partial analysis, labelled as such.

Write conclusions in a readable file or answer, with references that let the user find the supporting material. The optional research_assess tool can save an analysis with ordinary evidence references; attaching it to a prior record is optional. Do not substitute registration or metadata for doing the analysis.

See references/comparisons.md for common comparison mistakes.
