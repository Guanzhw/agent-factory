# 研究工作台治理与验收（2026-11-18）

基线为 `9a0201f`。下表以本次代码和测试为准。浏览器用 Chromium，模型服务为本地 HTTP 协议夹具，任务实际经过 PostgreSQL、Agno 队列和文件工具。

| 审计项 | 用户可观察的变化 | 验证 |
| --- | --- | --- |
| 01、02 成员入驻 | `uv run agent-factory local` 检查现有 PostgreSQL，配置回环 HTTPS 并初始化首位账号管理员。管理员可新建本地成员、重置本地密码，或单独登记外部身份。 | 空库首次设密中断后重启，从浏览器登录、配置模型、收取文件结果。再次启动时证书与密钥字节一致。第二位成员换密后旧密码被拒绝，外部目录成员的重置请求返回 409。 |
| 03 发送恢复 | 首轮提交失败后保留原文。用户可解除等待并保留原回执。模型撤销后可直接修改选择。 | Chromium 分别截断发送、截断已执行操作的响应、模拟明确拒绝。核对原回执后只观察到一轮和一次文件写入。 |
| 04、12 附件与分支 | 首条消息和追问可附加浏览器本地文件。相对文件链接在当前会话下载，栅格图片可直接显示。新分支记录创建时是否复制 Git 工作树，旧分支引导用户核对文件。 | 上传 CSV，经原生工具读取、生成 PNG，浏览器解码图片并逐字节核对下载。重复文件名返回 409，无 Git 分支的文件列表为空。 |
| 05、06 来源与上下文 | 同事问答支持中文双字匹配、分页摘录和按来源读取全文。资料撤回后只沿用能确定独立的早期轮次，丢弃可能含派生信息的旧摘要。 | 151 条合成材料，其中 149 条双方可读，逐页读取后无重复或私有材料。真实队列的下一轮协议载荷保留早期独立回答，排除已撤资料、派生回答、受影响纠正和旧摘要。 |
| 07 研究记录 | 新观察、评估和实验记录默认私有。显式选择团队可见时使用已有发布与共享机制。旧记录保留原可见性。 | 验证私有记录、显式团队发布，以及共享实验的后续私有评估。 |
| 08 历史 | 侧栏由数据库按最后更新时间与 ID 排序，以标题跨页查询。列表仅投影侧栏所需字段，详情按需刷新。 | 40 个会话分页无重复。更新最早会话后它回到首页，浏览器能搜到另一页的标题。 |
| 09、10 模型与工具 | 设置区分已保存和当前版本的文本连接验证，手动验证会发出可能计费的请求。模型失败可跳转到本轮连接。Git 行内评论、发现决策按任务上下文提供，委派可附带交接摘要。 | 本地提供方成功和 HTTP 401 均已验证。工具协议、思考、Stop 等能力仍由各自的原生任务测试覆盖。 |
| 11 文件和实时开销 | 浏览器按目录读取文件，文本预览默认请求前 64 KiB，成员可继续展开或完整下载。 | 核对目录读取、过期预览、完整下载和不可读目录。并发观察见下表。 |
| 13–15 表单、MCP 与键盘 | 账号和工具表单使用一致的前景与底色。发现失败提示检查地址和凭据。选择器打开时聚焦可用模型，Esc 返回触发按钮。 | Chromium 的浅色、深色偏好下，两个标签均为 14.56∶1，两个启用按钮均为 10.68∶1。不可达的本地 MCP 地址产生可重试提示。检查键盘焦点。 |

## 并发打开既有会话

每个成员使用自己的已登录浏览器上下文和一个空会话，同时导航至会话页。从发起导航计时到会话标题可见。SQL 次数为应用的 Store 与 Agno 两个 SQLAlchemy 引擎在该窗口内的总执行次数，含后台工作。通过独立连接约每 50 毫秒抽样目标库的连接数和等待 PostgreSQL 锁的连接数。

| 并发成员 | 首屏中位数 | 最慢首屏 | SQL 总次数 | 数据库连接峰值 | 等锁连接峰值 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 1.70 秒 | 1.70 秒 | 140 | 8 | 0 |
| 5 | 2.29 秒 | 2.57 秒 | 452 | 17 | 1 |
| 20 | 11.04 秒 | 15.04 秒 | 1772 | 36 | 2 |

浏览器与服务共享 4 vCPU、16 GiB 的 Linux 容器，同时有其他独立数据库的回归任务。各档只采样一轮。20 人同时打开的耗时值得继续剖析。生产服务器容量、长历史、同时推理、外部模型、外部 OIDC 和 Windows 人工首次安装仍需独立验收。
