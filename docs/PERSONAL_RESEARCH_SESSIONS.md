# 使用研究助手完成一个目标

本指南适用于已经启动并可登录的 AutoResearch。首次安装请先完成 [Windows 本地启动](WINDOWS_LOCAL_START.md)。默认 `agent-factory` 和默认前端构建都打开同一个自主研究工作界面。

## 配置你的模型

1. 在工作界面点击 **配置我的模型**，打开 **我的模型/API**。
2. 选择账户可用的模型预设，或填写提供方给出的 API 地址、模型 ID 和协议。
3. 填入自己的 API 密钥，或选择已保存且匹配该端点的凭据。
4. 保存模型。输出上限、上下文窗口与自动整理阈值均可留空；有提供方明确参数时，可在 **模型参数** 中填写。
5. 返回工作界面，在 **使用模型** 中确认该连接可选。

保存配置不会调用模型。研究内容会发送给所选提供方；密钥加密保存，不在界面回显。更新同一模型连接或工具配置后，下一轮读取当前配置；已经开始的任务仍保留原绑定。

OpenCode Go 的当前预设及字段见 [OpenCode 模型配置](OPENCODE_GO.md)。DeepSeek V4.1 Flash 的真实 CPU 实验使用过 16384 的输出额度；该值是一个已运行示例，不是所有任务的推荐上限。留空时不额外发送项目默认输出上限，由模型服务决定；推理内容也可能占用提供方的输出额度。

## 开始对话

1. 在消息框写下问题、可用输入和期望产物。
2. 确认 **使用模型**，点击 **发送消息** 或按 Enter；Shift+Enter 换行。
3. 页面显示真实回复片段和工具行动。需要补充背景时，可在会话设置中填写补充要求；名称会自动生成，也可以自行填写。

无需填写工具次数、委托深度或授权期限。设置和模型配置使用同一页面外壳，返回后保留草稿。引用已有项目是可选项。

例如，在已启用 Python 命令的环境中，可以提交这个小型目标：

> 用 Python 标准库比较普通 Monte Carlo 和方格分层采样估计 π 的误差。每种方法分别使用 100 和 400 个二维样本，种子取 0 到 9。生成 experiment.py、results.json 和 reproduce.md，运行脚本，检查结果并解释局限。

可选的补充要求可以写成：

> 只使用合成数据和本地 CPU，不安装依赖。三份文件生成并确认可复现后停止。遇到缺少工具或执行错误时报告实际原因，不编造结果。

这只是一次试用任务，不是平台强制的研究流程。助手自行决定读文件、编写代码、运行命令和分析结果的顺序。引用已有项目是可选项。

## 核对结果

对话中会直接显示当前行动与结果，较早的操作和原始记录可以展开：

- 对命令，核对工作目录、退出状态、标准输出和错误输出。
- 对文件，核对路径和写入回执。需要复现时，在准备好的环境中执行交付的复现命令。
- 对结论，检查输入、比较条件、计算结果和局限。任务显示完成不保证科学结论正确。
- 对未知结果，打开原任务或原操作记录继续核对。另建任务不能证明上次操作没有发生。

刷新页面只查询原记录，不会重新创建研究任务。后台仍可执行之前已接受的任务或同事回复触发的继续意图。

## 补充、继续或停止

运行中提交纠正后，页面先显示 **待纳入研究请求**。助手在后续模型请求中接收纠正；正在执行的命令不会被改写。**已纳入研究请求** 表示内容已发送，不表示模型一定遵守。

当前轮结束且原操作状态允许继续时，继续输入并点击 **发送**。项目不再用旧的八轮额度或每轮次数截断会话。已知模型窗口时，使用 token 阈值整理上下文；窗口未知时不会猜一个统一字符上限。原文和操作记录仍保留。

要停止当前会话，点击 **请求停止**，然后等待停止回执。**正在停止** 不是停止成功。停止会请求结束本任务树内的受控子任务，也会取消尚未采用的自动继续安排。它不会取消同事已经接受的独立任务。

如果页面提示操作结果未知，先核对原记录。不要通过反复点击开始或换一个会话绕过未知结果。

## 按需要使用协作能力

需要长期偏好时，直接告诉助手要记住、纠正或忘记的内容，例如“记住：回复先给复现步骤”。在工具记录中核对实际保存结果。个人偏好属于当前成员，不会自动共享给同事。

需要分工时，在目标中说明子任务和文件范围。助手可创建临时子助手，并在原会话中汇总结果。多人修改同一文件没有自动编辑隔离，分工时明确文件归属。

需要同事意见时，在 **本会话的同事问答** 中选择已开放的助手。助手也可自主查询和提问。只发送问题文本，不自动附带你的全部历史或凭据。对方回复到达后，已保存的继续意图可触发后续轮，不需要你逐条批准。人工选择回复 **用于下一轮** 时，还需要提交下一轮指令。

同事的任务由对方管理。收到回复不表示你的研究已完成；引用来源是否仍可访问，以当前回执为准。消息与恢复细节见[助手消息契约](ASSISTANT_MESSAGING.md)。

## 处理环境缺项

默认启动会创建研究工作目录并接入文件与命令工具。可按[本地启动指南](WINDOWS_LOCAL_START.md#启用本地文件与命令)更换工作目录或命令路径；若部署显式关闭了工具，界面会显示实际可用情况。已配置的个人 CLI/MCP 会在新轮中接入，不需要另行手工绑定会话。

代码项目需要目标仓库和实际运行依赖。先在目标中说明仓库版本、测试命令和允许的安装操作。平台不会在启动时替你准备所有项目依赖；是否能联网、安装依赖或调用远端计算，取决于所选工具和环境。

当前会话没有 token 或费用计量，也没有 CPU、内存和进程数硬隔离。命令以服务账号权限运行。远端 GPU 绑定和分配尚未实现，不能把 SSH 连接成功当作 GPU 实验已可用。
