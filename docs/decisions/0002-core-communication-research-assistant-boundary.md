# 通用通信与长期研究助手的责任边界

Accepted（仅责任边界决定），2026-10-25。依据用户在第五、六轮访谈中的明确确认；尚未实施，不代表整场访谈结束或开始实施的授权。

长期研究助手属于研究应用，研究业务策略由研究应用负责。底座提供通用身份、运行和通信能力；A2A 等通用 agent 通信归属底座，不混入研究业务策略。本阶段不构建一个跨所有应用的总 Personal Agent。

这一分解让通用通信可供不同应用复用，同时保留研究助手的领域职责。将全部能力放在 Research 内部会重新形成应用耦合；现在构建跨所有应用的总助手则会扩大本阶段的职责范围。选择上述边界意味着研究应用通过底座能力接入，而不能将科研策略作为通用通信的前提。

这项决定值得单独记录：跨应用依赖建立后，改变责任归属的成本较高；缺少解释容易让后续开发再次把通用通信藏入 Research；通用复用与应用内部统一定制之间存在实际取舍。这里记录的是边界及其理由，不是已经实现的架构或容量结论。

具体消息协议、存储、唤醒机制和接入接口的设计尚未确定。本决定不选择这些实现，也不替代其他仍在进行的访谈问题；当前讨论事实与未决项见 [CONTEXT.md](../../CONTEXT.md)。
