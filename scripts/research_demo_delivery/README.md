# Agent Factory · 研究工作台交互演示

这是纯前端演示，不连接真实账号、模型、GPU、数据库或外部 API。图表、团队经验、助手回答都是固定合成内容；资源列表为空，不能保存真实凭据或运行研究。请勿输入真实秘密。正式 UI 尚待用户体验确认。

## Windows 启动

1. 将 ZIP 完整解压到一个目录。
2. 在该目录打开终端，运行 `py -m http.server 8765 --bind 127.0.0.1`。
3. 浏览器打开 **http://127.0.0.1:8765/**。不要直接双击 index.html。
4. 结束后在终端按 Ctrl+C。

需要 Python 3 和现代浏览器；不需要 npm、Node、Python 第三方包或网络服务。macOS/Linux 可将 `py` 换为 `python3`。服务器只绑定本机回环地址，不是公网预览；端口已占用可改为 8766，并相应更改浏览器地址。

## 体验路线

默认以演示 Alice 进入独立平台首页。点击「进入 AutoResearch」→项目→实验/证据→返回工作台→返回平台。可新建演示项目、筛选团队经验、试用固定助手回复和资源入口。

头像菜单可退出，再选「成员 Bob」体验独立项目空间；管理账号入口仅显示不支持提示。演示 persona 与新建项目仅保存在当前浏览器标签页 sessionStorage，刷新保留；关闭标签页后通常清除。无 token、cookie、密码或服务端账号。新开标签页可重置为 Alice。

所有 fetch 被包内固定 fixture 接管。未知 API 返回本地错误，外部 URL 拒绝；不会把内容上传。附件只显示文件名，不读取或上传文件。浏览器模拟身份不代表生产登录验收。

页面 JS/CSS 来自已通过独立视觉 QA 的冻结构建，来源见 BUILD.json。保留的第三方许可见 LICENSES.txt。
